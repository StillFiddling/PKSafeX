# PKSafeX

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE)
[![Release](https://img.shields.io/github/v/release/StillFiddling/PKSafeX?label=release)](https://github.com/StillFiddling/PKSafeX/releases/latest)

**PKSafeX 是一款安卓端的宝可梦离线银行，是基于 [PKSafe](https://github.com/DeffoNotAlex/PKSafe) 的简体中文修改版（非官方 fork）**，
基于 [PKHeX](https://github.com/kwsch/PKHeX) 的存档编辑内核，面向 Android 纯触屏手机做了完整中文化与触摸化改造。

> 本项目与原作者 DeffoNotAlex、kwsch，以及 Nintendo / Game Freak / The Pokémon Company 均无隶属或背书关系。
> 这是社区修改版，仅按 GPLv3 分发。

- 包名：`com.pksafe.x`（**与上游 `com.pksafe.app` 不同**，签名也不同，两者不能互相覆盖安装，数据各自独立）
- 版本：**1.1.0 正式版**（versionCode 68）
- 授权：[GPLv3](LICENSE)

## 1.1.0 更新要点

**横屏体验（本版改动最大的一块）**

- 横屏箱子页、银行页补齐底部导航：`箱子 ▸` / `银行 ▸` 互跳，不再"横屏进得去、出不来"。
- 底栏徽章重新排布，`A / Y / B / R` 全部恢复可用（此前横屏有键点了没反应）。
- 放大镜改成左上角浮层，不占格子；点空白自动收起，过滤条件保留，✕ 清空键回到行内。
- 「存入中 / 取出中」横幅改浮层，平时不占格子空间。
- 转屏重绑：横竖屏来回切之后首卡不再消失、不再被压成竖排，光标/选中/翻箱/滚动位置一并回填。
- 横屏银行页详情整块重写，与箱子页共用同一套卡片。

**宝可梦详情浮层（重做）**

- 卡片按内容撑高并固定居中，竖屏上限约 0.94 屏高（最高 760），不再贴底把招式裁掉。
- 招式区按「4 招位置」预留高度，招式少的宝可梦不会先变矮再弹回。
- **能力页六项修好了**：以前读的是队伍区战斗数值，盒内宝可梦恒为 0；现在按 种族值 + 个体值 + 努力值 + 等级 + 性格 现场计算，真在队伍里的直接用队伍数值。
- 名字 / 等级 / 性格单行截断；关闭浮层同时清选中态；「编辑宝可梦」改为复用同一实例，进入更快。
- 竖屏与横屏都是**一页看完**（三块同页，横屏三列并排，高度不足时滚动），不再需要按「切换」翻页。

**新增：切换存档浮层**

- 箱子页与银行页底部上滑浮层列出所有已导入存档，点一行就地切换，不用退回首页重进。
- 每行含游戏图标、训练家名，副标题「版本 · 训练家ID · 游戏时间 · 箱子数」，当前那份标「当前」。
- 点遮罩收起；列表为空、当前存档不在列表时各有专门提示；正在写回存档时行不响应点击。

**箱子与仓库**

- 存入 / 取出时目标格已有宝可梦，直接拦下并跳到本箱第一个空格，绝不覆盖。
- 银行里箱内换位直接换，不再每格弹确认；存入失败先清「存入中」状态，不再卡住重复触发。
- 银行页空格按 `A` 无操作，「创建宝可梦」入口下线。

**存档与数据安全**

- 所有写回走同一套事务：写前自动备份（滚动保留 20 份），失败回滚内存快照。
- 检测到游戏里已存过更新进度时，只把本次改动合并进去，不用旧快照整份覆盖。
- 判断存档新旧改用内容指纹，修掉「没在游戏里存过却弹『已取出（含并最新进度）』」的误报。
- 同一份存档同时以只读和可写条目出现时，去重优先保留可写那份。
- **仓库（`bank.json`）写盘失败不再被静默吞掉**：存入失败停在第一步，宝可梦留在箱子里、存档一字未动；取出后若仓库清理失败，会明确提示「存档已写入，仓库原格仍留一份副本，请手动删除」。
- 「添加文件」改为同时申请读写授权并持久化；只读授权提前给中文提示，不再甩 `MANAGE_DOCUMENTS` 英文报错。

**扫描与性能**

- 扫描统计口径改成「候选 N 个 / 成功识别 M 个」，单独添加的文件与画像命中的候选单独计。
- 添加存档的提示分流：真没识别到才说「没读到存档」，重复添加会说「这张存档已经在列表里了」。
- 冷启动不再整盘扫描，有缓存时第一帧出卡片，后台只校验真正变过的文件；图鉴精灵图预载移出主线程。

## 与原版的差异

- **全中文界面**：首页、箱子页、银行页、道具页、宝可梦编辑页、设置页文案全部简体中文。
- **纯触屏可用**：底部提示条每一枚"键帽"都可直接点按，等同按手柄同键；无手柄也能完成全部操作。
- **银行页重做**：补齐"存入/取出/抓取"流程，顶部存档条与箱子页同款版式。
- **顶部版式统一**：箱子页 / 银行页顶部只保留「游戏图标 + 训练家名 + 游戏名 + 右上角互跳按钮」。
- **键位调整**（见下文"键位"）：叫声 R3→R1，进出银行 R1/L1→R2/L2。
- **首页退出确认**：按 B（手柄 B / 系统返回 / 点底部 B 徽章）先提示，再按一次才退出。
- **宝可梦编辑页**：性别显示为 ♂ / ♀ / —，返回与保存按钮中文，操作说明移到保存按钮上方。
- **包名改为 `com.pksafe.x`**，避免与上游 APK 混淆。
- **立绘离线可用**：图鉴先读本地、再补网络，缺图显示"?"；HOME 立绘缓存迁到 AppData 不再被系统清理；
  新增 ZIP 精灵包导入与多源容错下载。

## 安装与升级

1. 直接覆盖安装（与 1.0.8 ~ 1.0.10 测试包同一签名，无需卸载）。
2. 首次启动若提示「所有文件访问」，按引导授权，否则写回存档会失败——多数模拟器的存档在 `Android/data` 下，没有这个权限读不到。
3. 存档建议用「添加文件夹」整目录加入；逐个「添加文件」是单文件授权，写入权限更容易被系统收回。
4. 改完存档后先**退出模拟器**再进游戏；模拟器仍开着会把它自己那份回写覆盖掉。

## 立绘与离线导入

设置页提供两种方式补齐宝可梦形象，二者写入同一套缓存目录：

| 方式 | 说明 | 存放位置 |
| --- | --- | --- |
| 下载 HOME 立绘 | 联网拉取 PokeAPI 的 HOME 立绘（约 120 MB），主源不可达时自动换镜像 | `AppData/home_sprites/{slug}.png`（闪光在 `shiny/`） |
| 导入 HOME 立绘精灵包（ZIP） | 自己先下载好 ZIP，再从本地导入；流式解压，可重复导入 | 同上 |
| 下载动态立绘 | 联网拉取 Showdown 的动态 GIF（约 200 MB） | `AppData/sprites/{ani,ani-shiny}/{slug}.gif` |
| 导入动态立绘精灵包（ZIP） | 同上，离线导入 GIF 包 | 同上 |

ZIP 包命名契约（宽容匹配，目录层级不限，只要路径里有对应目录名）：

- HOME 立绘：`*.png`，路径含 `home/`；文件名须为 `025.png` / `666-archipelago.png` 这类"数字(-后缀)"形式；
  路径含 `shiny/` 视为闪光版。
- 动态立绘：`*.gif`，路径含 `ani/`（普通）或 `ani-shiny/`（闪光）；文件名为小写英文 slug，如 `charizard.gif`。

导入时会校验文件头与体积（PNG ≥ 8 KB、GIF ≥ 2 KB），坏文件直接跳过并计数，不会污染缓存。

> 网络下载异常时，优先用"导入 ZIP"这条路径（脱离境外网络），其次在设置页重新下载。
> 缓存目录不会被系统清理，重装应用前如需保留，请自行备份 `AppData` 下这两个目录。

## 构建

要求：.NET 10 SDK + MAUI workload、Android SDK (API 26+)。

```bash
dotnet build PKHeX.Mobile/PKHeX.Mobile.csproj -f net10.0-android -c Release
dotnet build PKHeX.sln
```

产物：`PKHeX.Mobile/bin/Release/net10.0-android/com.pksafe.x.apk`（未签名），自行用 apksigner 签名后安装。

## 已知情况

- 极低概率的写入中断：需要在几十毫秒窗口里被系统强制结束进程，测试阶段未复现，量级远低于千分之一。真碰上时软件不会自动修复，请用模拟器即时存档或手上的备份恢复。
- 内部存储不足：写入前按存档大小落盘，剩余空间小于存档时写入会失败并明确提示「写入失败」。
- 备份仅可查看（设置页显示份数与时间），不提供一键恢复——多存档场景下备份命名无法可靠区分目标存档，误覆盖风险大于收益。
- 平板 / 双屏掌机尚未做专门布局，按手机比例拉伸显示。
